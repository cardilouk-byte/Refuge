Telechaje aplicasyon SIGES la (ZIP)

Fichye a genyen tout kòd lekol la: sit vitrin, pòtay, nòt, bulletin, presans, quiz, cahies, backup, Excel… (san baz done ou ni medya ou — sekirite).

Telechaje ZIP aplicasyon an
  1. Ekstrè ZIP la nan yon dosye sou òdinatè w la.
  2. Enstale pakè yo: python -m pip install -r requirements.txt
  3. Bazi done a: python manage.py migrate
  4. Konto admin (premye fwa sèlman): python manage.py createsuperuser
  5. Lanse sèvè a: python manage.py runserver → louvri http://127.0.0.1:8000/
Si ou gen deja yon db.sqlite3 ak dosye media/, pa efasé yo — kopye yo nan nouvo dosye a pou ou pa pèdi done lekòl ou la.

# LNFCL — Sit wèb dinamik Django

Sit ofisyèl **Lycée National François Cappoix de Limonade** (LNFCL).
Deviz: *« S'instruire pour mieux servir »*.

> Kòd konplè sit la ap vini sou branch `vibe/lnfcl-site-fc50d6`.

## Kache Django a

- Panneau kontwòl la pa nan `/admin/` — li nan yon adrès sekre ou chwazi.
- Chaje adrès la nan fichye `.env` : `ADMIN_URL=kontwol/` (ou ka mete nenpòt non).
- Pa gen mo "Django" ki parèt sou entèfas la; paj login panneau a gen stil lekòl la.
